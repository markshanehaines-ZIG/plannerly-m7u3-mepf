# Plannerly M7U3 MEPF Starter Pack

> **Masters Assignment – M7U3**
> Plannerly-based MEPF information requirements, verification,
> and AI-assisted cost estimation.

GitHub is the **drafting and evidence environment**.
Plannerly is the **live system** for Scope, Verify, Documents,
and MIDP/TIDP workflow execution.

---

## Purpose

This repository supports a trusted workflow:

1. Define clear MEPF information requirements.
2. Assign responsibility and milestones.
3. Create checkable verification rules.
4. Record how Plannerly Scope tasks roll into TIDP/MIDP logic.
5. Capture screenshots and exported evidence for final submission.

---

## Suggested Workflow

| Step | Where |
|------|-------|
| Draft wording and tables | This repository |
| Build live task structure | Plannerly Scope |
| Create responsibility assignments | Plannerly |
| Mirror checkable rules | Plannerly Verify |
| Export / screenshot evidence | Back into `assets/` |
| Assemble final narrative | `docs/07-final-submission.md` |
