# 02 – Purpose and Scope

## Project Context
This assignment uses a representative MEPF information package to
demonstrate how structured requirements, clear responsibilities, and
checkable verification rules enable AI-assisted cost estimation.

## In Scope

| MEPF System | UniClass / OmniClass Code | Plannerly Scope Task |
|-------------|--------------------------|----------------------|
| Mechanical – Ductwork | D3010 | `Mechanical – D3010 Ductwork` |
| Electrical – Cable Trays | E3010 | `Electrical – E3010 Cable Trays` |
| Plumbing – Pipework | D2010 | `Plumbing – D2010 Pipework` |
| Fire – Sprinkler Heads | D4010 | `Fire – D4010 Sprinkler Heads` |

## Out of Scope
- Structural elements
- Architectural finishes
- Site / civil works
- Any system not listed above

## Bounding Statement
> Only the four MEPF systems above are included.
> This scope is intentionally small to allow deep verification coverage
> rather than broad, shallow treatment.

## Key Assumptions
- Models will be provided in IFC format (IFC4 preferred).
- BIM Authoring tools: Revit MEP / AutoCAD MEP.
- Coordinate reference: project-shared coordinate file to be issued at
  Stage 2.
