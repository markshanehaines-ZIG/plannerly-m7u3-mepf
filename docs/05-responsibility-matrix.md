> Assign roles against each MEPF Scope task.

## Role Definitions

| Short Code | Role |
|------------|------|
| MEP | MEP Design Lead |
| BIM | BIM Manager / Coordinator |
| PM | Project Manager |
| CLIENT | Client / Employer's Agent |
| EST | Cost Estimator |

## RACI Key
- **R** – Responsible (does the work)
- **A** – Accountable (signs off)
- **C** – Consulted (input required)
- **I** – Informed (notified on completion)
